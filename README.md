# Claude Code + Qwen Assignment

## Objective

This assignment demonstrates:

* Installation of Claude Code
* Installation of Ollama
* Downloading and running the Qwen3:4B model
* Python integration with the local model
* GitHub repository management

## Files

* `app.py` - Python program that sends prompts to the Qwen model through Ollama.
* `README.md` - Project documentation.

## Commands Used

```SHELL
ollama pull qwen3:4b
ollama run qwen3:4b
python app.py
```
